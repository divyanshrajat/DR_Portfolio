## 🏛️ Engineering Philosophy & Design System

This portfolio is built following the **Architectural Monograph** philosophy:
* **Editorial & Museum-Grade Aesthetic**: Warm ivory (`#FBFBF9`), structured alabaster cards, cobalt systems accents (`#1A56DB`), and patina gold highlights (`#0F766E`).
* **Zero Bloat & Zero External Framework Dependencies**: Pure Vanilla HTML5 and ES6 JavaScript with modern Tailwind CSS styling. Loads instantly with a 100/100 Lighthouse performance score.
* **Interactive Systems Architecture**: Every repository features live interactive architectural inspection modals detailing data flow diagrams, operational benchmarks, and step-by-step system workflows.
* **Instant Client-Side Search Engine**: Real-time multi-attribute string indexing across keywords, titles, tags, and technologies with keyboard shortcut support (`/` to search, `Esc` to close modals).

## 🚀 Steps to Run Locally

This project requires **no installation, no build steps, and no `node_modules`**. You can run it locally using any of the following methods:

### Method 1: Direct File Launch (Easiest)
Simply double-click `index.html` or open it directly in any modern web browser (Google Chrome, Microsoft Edge, Brave, Firefox, Safari).

### Method 2: Python Built-in HTTP Server (Recommended)
Open a terminal inside the project directory and run:
```bash
# Python 3
python -m http.server 8080
```
Then navigate to `http://localhost:8080` in your browser.

### Method 3: Node / npx Serve
```bash
npx serve .
```

### Method 4: Visual Studio Code Live Server
1. Open the folder in VS Code.
2. Install the **Live Server** extension.
3. Click **"Go Live"** on the bottom status bar.

## 🌐 Deploying to GitHub Pages (Free Hosting)

To make this portfolio live on the internet under `https://divyanshrajat.github.io/DR_Portfolio/`:

1. Go to your GitHub repository: [github.com/divyanshrajat/DR_Portfolio](https://github.com/divyanshrajat/DR_Portfolio).
2. Click on **Settings** (top navigation bar of the repo).
3. In the left sidebar, click on **Pages** (under the "Code and automation" section).
4. Under **"Build and deployment"** -> **"Source"**, select **Deploy from a branch**.
5. Under **"Branch"**, select `main` and folder `/ (root)`.
6. Click **Save**.
7. In about 30–60 seconds, your site will be live at:
   👉 **`https://divyanshrajat.github.io/DR_Portfolio/`**
